# Диктовка

Одна кнопка на телефоне: говорите по-русски, текст появляется на экране сразу. Готовый текст можно поправить, скопировать или стереть. Учётной записи и отправки текста нет.

Звук распознаётся в самом браузере. Запись и текст никуда не уходят.

## Как открыть в Chrome на Android

Микрофон включается только на защищённой странице: адрес должен начинаться с `https://`. Ссылка `http://` и открытие файла с телефона не сработают. `localhost` считается защищённым только если страница открыта на самом телефоне.

1. Выложите эту папку на любой обычный HTTPS-хостинг (отдельные заголовки COOP/COEP не нужны) и откройте адрес в Chrome.
2. Либо на компьютере, в одной сети Wi-Fi с телефоном:

```bash
python3 scripts/serve-https.py
```

Скрипт печатает адрес вида `https://192.168.x.x:8443`. Откройте его в Chrome, подтвердите предупреждение о сертификате и разрешите микрофон.

Первый запуск скачивает модель (44 МБ) и движок (около 5,5 МБ). Пока идёт загрузка, на экране есть полоса и размер. После этого диктовка работает без сети: страницу и модель держит сервис-воркер, распакованная модель остаётся в памяти браузера.

## Почему не Web Speech API

В Chrome обычный `SpeechRecognition` / `webkitSpeechRecognition` отправляет звук на сервер. Режим `processLocally: true` запрещает сеть, но в Chrome для Android его нет (настольный Chrome — да, Android — нет). Поэтому страница его не вызывает.

Распознавание делает [vosk-browser](https://github.com/ccoreilly/vosk-browser) 0.0.8: WebAssembly в воркере, без общей памяти и без COOP/COEP. Модель `vosk-model-small-ru-0.22` (Apache 2.0) лежит в `models/` и читается только с этого же сайта.

## Ограничения

Маленькая модель рассчитана на телефон, но ошибается чаще большой: на чужих записях это примерно от 12% до 32% слов в зависимости от шума. Знаков препинания нет, слова чаще строчные. На слабом телефоне слова могут отставать на долю секунды. Первая распаковка модели после скачивания занимает заметное время.
